# Data card

The repository contains only tiny, hand-authored synthetic text/JSON fixtures under
`examples/egolite/`. They exist to test ResearchOps behavior, not model quality.

- No people, images, biometric data, ego video, or licensed dataset content is included.
- Metric and resource values are explicitly marked `synthetic: true`.
- The fixture must not be used to claim hardware throughput or pose accuracy.
- Real deployments must document dataset origin, consent/license, minimization,
  retention, access scope, split construction, manifest digest, and deletion procedure.
