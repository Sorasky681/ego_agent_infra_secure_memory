EgoAgentOS 是面向 Auto Research 的可验证 Agent Infra：以 AgentTeams Manager–Worker 动态协作为编排面，以原创 RXP/1 协议把一次实验冻结为 Intent→单次精确授权 Grant→Receipt→Evidence→独立 Decision，并用 MatrixLedger 阻止漏跑实验格后选择性下结论。7 个分权 Agent、6 个 digest-pinned Skill 与 PostgreSQL 控制面共同提供审批、恢复、回滚、审计和可移植执行合同。14 类对抗场景由独立 oracle 评测，target 未实连时必须 SKIP 且 release gate 失败。开源包含完整代码、PPT/PDF、8 分钟演示脚本和确定性 proof bundle；当前 GPU workload 与模型指标均明确标注 synthetic，live AgentTeams、PolarDB/PITR 与生产签名未冒认。
