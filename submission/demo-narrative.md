# Demo narrative (6–8 minutes)

## 0:00 — The operating problem

Open with one sentence: “An experiment is not a result until code, data, run, metric,
review, and decision are bound by evidence.” Show the active EgoLite task; call out that
model/hardware values are synthetic while the control plane is real.

## 0:45 — Goal and separation of duties

Reset the task. Freeze the ≥10 FPS and ≤5% MPJPE-degradation criteria. Show PI, Scout,
Architect, Runtime, Evaluator, Reviewer, and Memory Curator identity boundaries. Run to
the next gate and open the generation-scoped, hash-chained control-plane audit. Say
explicitly that local role handlers are deterministic fixtures, not a live Matrix room.

## 2:00 — The approval cannot be talked around

At APPROVAL, show R2 modeled cost, exact action digest, expiry, and rollback pointer.
Point out that advance controls are locked before approval. Approve once; explain that
the browser retains the one-time token only for this generation. Cite the automated
scope/replay tests rather than staging a misleading post-completion replay.

## 3:00 — Recover a real class of lab-infra failure

Continue the replay. The fixture records low GPU utilization and CPU/hash saturation.
Show the recorded diagnosis and the canonical dataset-manifest procedure: publish-time
full hashing, runtime digest verification. The local API does not invoke the dataset MCP
or switch real workers; never present the fixture as a 4090 benchmark.

## 4:15 — Metrics are calculated, not narrated

Open baseline and candidate raw artifacts, paired delta/CI, evaluator version, split,
and digests. Explain that an LLM may summarize but cannot calculate or change them.

## 5:15 — Evidence before decision

Show the seven-kind ledger and independent Reviewer. Explain that 7/7 presence is still
`HOLD` until the backend gate actually runs. The local autorun commits its bounded
Decision only after PASS; inspect the audit event and bound run-manifest digest.

## 6:15 — The system learns safely

Archive the verified failure and procedure as episodic/procedural memory. Show a Skill
candidate while the Nacos status remains draft/not configured. Close with: “EgoAgentOS
does not merely run experiments; it manages a trustworthy research production line.”

## Claim boundary to say aloud

The local API/Web/SQLite control plane and deterministic replay are running. The four
MCP servers are independently tested, including a loopback transport handshake; they are
not the source of the Web replay artifacts unless the explicit execution bridge is used.
AgentTeams/Matrix, Higress, Nacos, Aliyun services, a real dataset, and live GPUs remain
not configured in this submission.
